プライバシーポリシー

対象: Chrome 拡張機能「アカウント作成君」
最終更新日: 2026年9月17日
本ポリシーの公開URL: https://naokijodan.github.io/account-creator-privacy/

本拡張機能に入力した氏名（ふりがな含む）・郵便番号・番地・建物名・部屋番号・電話番号、および利用中の進捗状況／チェックリストの状態は、すべて利用者のブラウザ内（chrome.storage.local）にのみ保存されます。開発者が運営するサーバーへ送信されることは一切なく、販売・第三者提供も行いません。 本拡張機能が行う外部通信は次の2つだけです。(1) 住所検索のために入力した郵便番号（7桁の数字）のみを zipcloud（https://zipcloud.ibsnet.co.jp/）に送信します。(2) ガイドの手順データ（公開情報のJSON）と、各ステップの説明用画像を https://naokijodan.github.io/account-guide-data/ から取得しますが、この通信には利用者の入力内容や個人情報は一切含まれません。

1. 収集する情報

本拡張機能は、以下の情報をブラウザ内（chrome.storage.local）でのみ扱います。これらの情報は、下記「2. データの送信・外部通信」に明記した郵便番号を除き、外部のサーバーに送信されることはありません。

  • 氏名（姓・名、ふりがな含む）
  • 郵便番号（住所検索のため、7桁の数字のみ一時的に外部サービスへ送信されます。詳細は「2. データの送信・外部通信」を参照）
  • 番地・建物名・部屋番号
  • 電話番号
  • ガイドの進捗状況・チェックリストの完了状態

本拡張機能は、メールアドレス等のアカウント情報、閲覧履歴、Cookie、位置情報など、上記以外のいかなる個人情報も収集しません。

2. データの送信・外部通信

本拡張機能が通信する外部サービスは、次の2つのみです。

  • zipcloud（郵便番号検索API） — https://zipcloud.ibsnet.co.jp/
    利用者が郵便番号を入力して検索したときに、入力された郵便番号（7桁の数字）だけが zipcloud に送信されます。zipcloud からは、その郵便番号に対応する公開の住所情報（都道府県・市区町村・町域名）が返されます。氏名・番地・建物名・部屋番号・電話番号など、郵便番号以外の入力内容が zipcloud に送信されることはありません。
  • 手順データ・画像の取得 — https://naokijodan.github.io/account-guide-data/steps.json
    ガイドの手順・案内文を最新の状態に保つため、上記URLから静的な公開JSONデータを取得（GETリクエスト）します。あわせて、各ステップの説明用の見本画像（スクリーンショット）を同じ https://naokijodan.github.io/account-guide-data/ 配下から取得することがあります。これらはいずれも誰でも閲覧できる公開データ・公開画像を取得するだけの通信であり、利用者の入力内容・個人情報は一切送信されません。

本拡張機能はこれ以外の外部サーバーとは一切通信しません。eBay・Payoneer のウェブサイトへアクセスすること、それらのページを読み取ったり操作したりすること（スクレイピングやコンテンツスクリプトの挿入を含む）は一切ありません。

3. データの保存

入力した氏名・郵便番号・番地・建物名・部屋番号・電話番号、および進捗状況／チェックリストの状態は、次回サイドパネルを開いたときに続きから利用できるよう、Chrome の拡張機能用ローカル保存領域（chrome.storage.local）にのみ保存されます。この保存先は利用者のパソコン内のみであり、外部に送信されることはありません。

保存された内容は、画面上のクリア操作を行うか、本拡張機能をアンインストールすることでいつでも消去できます。

4. 権限の利用目的

  • ストレージ (storage): 入力した氏名・郵便番号・番地・建物名・部屋番号・電話番号、および進捗状況／チェックリストの状態を、利用者のパソコン内（chrome.storage.local）に保存し、次回起動時に復元するためにのみ使用します。データが外部に送信されることはありません。
  • サイドパネル (sidePanel): ガイド画面をブラウザのサイドパネルに表示するためにのみ使用します。
  • ホスト権限 (https://zipcloud.ibsnet.co.jp/*): 入力された郵便番号から公開の住所情報を検索するために、zipcloud API へアクセスするためにのみ使用します。
  • ホスト権限 (https://naokijodan.github.io/*): ガイドの手順データ（公開JSON）と、各ステップの説明用画像を取得するためにのみ使用します。個人情報の送信には使用しません。

5. 第三者への提供

本拡張機能が外部に送信するのは、住所検索のために zipcloud へ送信する郵便番号（7桁の数字）のみです。氏名・番地・建物名・部屋番号・電話番号・進捗状況を含む、それ以外の入力内容や個人情報を第三者に提供・販売・共有することは一切ありません。

6. アナリティクス・トラッキングについて

本拡張機能には、アクセス解析・広告・トラッキングの仕組みは組み込まれていません。利用状況の収集や外部への送信も一切行いません。

7. eBay・Payoneerとの関係

本拡張機能は、eBay・Payoneer のアカウント作成手順をサイドパネル上でガイドし、登録に必要な英語表記の住所・氏名・電話番号をその場で作成してコピーできるようにするツールです。eBay・Payoneer のページへのアクセス、閲覧、自動入力、スクレイピング、データの送受信は一切行いません。表示された内容を各サービスの登録画面へ入力するかどうかは、利用者ご自身の操作によります。

8. 子どものプライバシー

本拡張機能はアカウント情報や認証情報を収集しないため、年齢を問わずご利用いただけますが、氏名・住所の登録は保護者の管理のもとでご利用ください。

内容を変更する場合は、本ページの「最終更新日」を更新して掲示します。
